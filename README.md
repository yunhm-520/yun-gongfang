# 云工坊（yun-gongfang）

一组**纯前端、零依赖、打开即用**的图片与鼠标指针制作工具。所有处理都在浏览器本地完成，图片不上传服务器，无需安装、无需联网即可使用核心功能。

> 适合个人用户制作自己的鼠标指针皮肤、处理图片素材；也适合作为 Canvas 图像处理的学习示例。

## 包含的工具

| 工具 | 文件 | 作用 |
| --- | --- | --- |
| 🖼️ 图片工坊 | `图片工坊.html` | 图片调整（亮度 / 对比度 / 饱和度）、滤镜、缩放、旋转裁剪、马赛克、画笔、文字水印 |
| ✂️ 抠图工坊 | `抠图工坊.html` | 网格切分 + 魔棒抠图，把一张图里的多个元素拆成独立透明素材 |
| 🖱️ 指针工坊 Pro | `指针工坊.html` | 核心工具：抠图素材 → 设计 17 种指针角色 → 导出 CUR / ANI / INF 皮肤包 |

配套文档：`指针工坊_使用说明书.html`（图文并茂，含 01–10 章完整教程、FAQ 与附录）。

## 快速开始

1. 用现代浏览器（Chrome / Edge 113+）直接打开 `指针工坊.html`。
2. 打开一张图片 → 抠图 / 拆分元素 → 设计指针 → 调整热点 → 导出皮肤包。
3. 想先系统了解，打开 `指针工坊_使用说明书.html`，跟着「一分钟上手」走。

三个工具都是**单文件 HTML**：下载后双击即可运行，不需要起服务、不需要 npm install。

## 指针工坊 Pro 功能一览

- **素材处理**：魔棒抠图、网格切分、连通块自动拆分独立元素、边缘精修。
- **画质增强**：面积平均降采样（像素风 / 照片分流）、一键变清晰、WebGPU + Real-ESRGAN AI 超分（可选，需联网下载约 5MB 模型）。
- **标准尺寸**：任意素材一键生成 128×128 等标准指针画布尺寸。
- **17 角色独立作品**：每个指针角色（Arrow / Wait / Help …）保存自己的画布、图层、帧和热点，互不干扰。
- **实景试戴**：模拟桌面场景，按真实像素尺寸预览指针、热点与动画。
- **自动动画**：7 种动画预设（浮动 / 脉冲 / 旋转 / 弹跳 / 摆动 / 发光 / 淡入淡出）逐帧生成。
- **导出**：标准 Windows CUR / ANI 二进制文件，或非破坏式 INF 皮肤包 + ZIP。

## 技术架构

- 全部逻辑为原生 HTML + CSS + JavaScript，无框架、无构建步骤。
- 图像处理基于 Canvas 2D `ImageData` 逐像素运算；CUR / ANI 由 JS 直接拼装二进制（图标目录 + BITMAPINFOHEADER + XOR/AND 位图）。
- AI 超分通过 ESM 动态导入 `@websr/websr`，用 WebGPU 跑 Real-ESRGAN；透明度由独立的 Lanczos 蒙版贴回，保证透明边缘不糊。
- 所有文件读写用浏览器 `Blob` / `a[download]` 完成，全程本地。

## 运行测试（可选，供二次开发）

测试脚本从仓库根目录读取三个 HTML，请在本目录内运行：

```bash
cd work_cursor
node test_sr.js          # AI 超分 / 像素读取回归
node test_roles.js       # 17 角色独立作品
node test_fit.js         # 缩放质量
node test_tryon.js       # 实景试戴
node test_merge.js       # 抠图合并
node test_ptr2.js        # 指针编码逻辑（会生成 _ptr2_out 目录）
python verify_ptr2.py    # 二进制格式校验（需在 test_ptr2.js 之后运行）
```

依赖：Node.js 18+ 与 Python 3（仅二进制校验用）。运行工坊本身不需要这些。
