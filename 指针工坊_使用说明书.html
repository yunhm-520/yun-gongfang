01 · 它是什么 / 能做什么

指针工坊是一个单文件网页工具：用浏览器打开 指针工坊.html 就能用，不需要安装、不需要联网、不上传图片。 它把「做一套鼠标指针」这件事拆成三段，串在一个界面里：

① 抠图 / 素材

把海报、截图、立绘里的主体抠出来：魔棒、画笔修边、去浅底、去白边、裁切、一键变清晰。

② 指针设计

定尺寸、摆图层、补画细节、设热点（点哪儿生效）、做多帧动画。

③ 导出皮肤

打成 ZIP：17 个角色的 .cur/.ani + Install.inf + 安装脚本，双击即装。

能做到这些

  • 17 个指针角色一次配齐：正常箭头、忙碌、文本 I 形、手型链接、调整大小、移动、不可用…… 每个角色一份独立作品，切角色自动存档，导出时各出各的文件；没做的角色自动沿用当前这份。
  • 一键标准尺寸：不管素材是横图、竖图还是长宽比奇怪，一键裁空白 → 等比缩放 → 居中补透明，输出严格 128×128（也可选 32/48/64/96/256）。
  • 自动动画：旋转、弹跳、摇摆、呼吸、光晕脉冲等 7 种预设，一键生成 4~16 帧循环动画，还会按角色推荐动作（忙碌 → 旋转）。
  • 静态指针（.cur）和动画指针（.ani）：多帧就是动画，帧数和每帧毫秒数随便调，内置播放预览。
  • 多尺寸打包：一次导出 48/64/96 等多个尺寸，高分屏自动挑最清晰的那一档。
  • 不破坏系统：装完只是「鼠标属性 → 指针 → 方案」里多了一项，系统自带的 Aero 指针一个字节都不动。

不能做到这些（提前说清楚）

  • 不能做 macOS / Linux 指针——输出格式是 Windows 的 .cur / .ani。
  • 「🪄 一键变清晰」是插值放大 + 锐化（本地、免联网），不会无中生有；想要"重建细节"用旁边需要 WebGPU 的 🚀 AI 超分。
  • 没有「工程文件」保存功能。关掉页面前请把导出 ZIP 存好，原始大图另存一份（详见 限制说明）。
  • 不能超过 256×256：这是 Windows 指针的硬上限。
建议用 Edge 或 Chrome 打开。IE 和部分国产双核浏览器的「兼容模式」不支持本项目用到的画布 API，会白屏。 如果双击被系统用别的程序打开，右键 → 打开方式 → Microsoft Edge。

02 · 一分钟上手

只想最快做出一套能用的指针，照这 5 步走，全程约 3 分钟：

  1. 把图片拖进窗口打开后自动进入「① 抠图 / 素材」，画布上显示整张图。
  2. 点背景左侧 🪄 魔棒已默认选中，直接点图片的背景区域，同色背景会变成棋盘格（= 透明）。点不干净就把右侧「魔棒容差」往上调，再点没抠掉的地方。
  3. 点「📐 生成标准尺寸」（右侧「标准尺寸」卡片，默认 128）。它会裁掉四周空白、等比缩放、居中补透明， 一步得到严格 128×128，并顺手放进当前角色的画布、猜个热点、跳到「② 指针设计」。 想手动控制就改目标尺寸，或取消勾选后用「✅ 用作指针画面」。
  4. 确认热点画布上的红色十字就是"点下去"的位置。位置不对就在左侧点 📍，再在画布上点一下正确的点（箭头类通常是画布左上方的尖）。
  5. 导出并安装右上「📦 导出皮肤」→ 填皮肤名 → 「导出 ZIP」→ 解压 → 双击 安装皮肤.bat → 打开「鼠标属性 → 指针 → 方案」，选你的皮肤名 → 应用。
第 5 步的「应用」别漏。装完皮肤后，方案列表里会出现你的皮肤名，但必须点一次「应用」（或「确定」）才会真正生效； 部分系统还需要把鼠标移到桌面上晃一下才刷新。
装之前想先看看？第 4 步之后随时点顶栏 👁 试戴：会在模拟桌面上按真实尺寸预览， 鼠标移到正文/按钮/窗口边上会自动切换成对应角色，多帧作品还会循环播放。详见 5.8 实景试戴。

03 · 界面总览

整个界面是「顶栏 + 左侧工具条 + 中间画布 + 右侧参数面板 + 底部托盘」的五区结构，两条灰色分隔条可以拖动改大小； 切到 ② 时画布上方还会多出一条角色栏，随时告诉你正在编辑 17 个角色里的哪一个。

7角色栏（仅 ② 模块）画布正上方一条浅蓝横栏，写着「正在编辑 · 正常选择 / Arrow → pointer.cur」，右边 17 个角色胶囊可切换。右上「全部 17 个 ↗」直接打开导出面板看总览

把界面调成你习惯的样子

  • 拖动分隔条：画布与右面板之间的竖条左右拖（右面板 190~520px），底托盘上方的横条上下拖（96~420px）。
  • 收起面板：操作条右端的 ⇥ 收起右面板、⇩ 收起底部托盘，画布会立刻变大。
  • 窗口越大越好用：1080p 以上屏幕建议最大化浏览器，抠图时看得更清。
改过布局后不用记，工具不保存界面状态，下次打开会回到默认（右面板 300px、托盘 164px）。

04 · ① 抠图 / 素材

这一模块只干一件事：把你要的那块图干净地抠出来。抠完点「✅ 用作指针画面」就走人，不需要再切块、也不需要导出中间文件。

4.1打开图片

四种方式，任选一种：

方式说明
拖进窗口从资源管理器直接拖图片到页面任意位置。支持 PNG / JPG / WebP / GIF（GIF 只取第一帧）
Ctrl+V 粘贴截图后直接在页面里粘贴，最快。QQ/微信截图 → Ctrl+V 即可
「📂 打开图片」顶栏按钮，走文件选择框
拖入 .cur / .ani不是打开图片，而是把现成的指针载入 ② 设计模块去改（标题栏会变成文件名）
一次只拖一张图。同时拖进多张时，最终只会留下最后加载完的那一张。要处理第二张，等第一张做完（已点「用作指针画面」）再拖。

图片多大都行，工具内部按原始像素处理。但要注意：最后做指针时会被缩放到 256 以内， 所以抠图阶段没必要对一张 4000px 的海报精雕细琢——真正决定清晰度的是「缩小到 64 之前有没有先做去噪/锐化」。

4.2视图操作（抠图精度的前提）

操作效果
滚轮以光标为中心缩放，0.05× ~ 40×。放大到 12× 以上会出现像素网格
按住 空格 拖动 / 中键拖动平移画面
右下 适应 / 1:1整图完整显示 / 一个屏幕像素对应一个图片像素
左侧 ✋抓手工具（不按空格也能拖）
修边请一定放大到 20~40×。在 100% 视图下看着"干净"的边缘，缩到 32×32 之后往往是一圈脏点； 反过来，放大到 40× 修一遍，缩到小尺寸就干净得多。

4.3魔棒：点一下就抠掉一片

左侧 🪄（快捷键 W）是默认工具。在图片上点一下，与点击处颜色相近、并且相连的整片区域会变透明（棋盘格）。

三个参数

参数范围 / 默认怎么调
魔棒容差1 ~ 100，默认 30决定"多不像才算不同色"。背景是纯色但略有噪点时用 40~60；背景本身有渐变时可用 70+，但要小心把主体也吃掉
取样：连通默认只抠和点击点连在一起的那一片。适合"主体被背景包住"的情况
取样：全图—整张图里所有相近颜色都抠掉，不管连不连。适合"背景和主体间有白边隔开"或"多处同色背景"

点击时的三个动作

操作效果
单击抠掉这一片（把透明度的"不透明"往下压）
Shift + 单击继续抠另一片。效果与单击相同，只是习惯上用它来表示"接着来"
Alt + 单击撤回：把这一片按同样的颜色范围恢复到不透明。抠多了就用它救回来，比按 Ctrl+Z 更精准
点了没反应？按顺序排查：
  1. 左侧工具条上 🪄 是否高亮——如果高亮的是 ✂️ 或 🧽，点击当然不是抠图；
  2. 容差是不是被拖到了 1~5（几乎只能点中完全相同的颜色）；
  3. 你是不是点了「取样：全图」但背景颜色跨度很大——换回"连通"再点；
  4. 这一片是不是已经被抠过了（棋盘格处再点是不会有变化的）。

一次抠不干净怎么办

用分层推进：先用容差 30 点掉最纯的那片 → 调到 45 点剩下的过渡区 → 调到 60 点角落的阴影。 每次点击都是一次独立的撤销点，抠坏了 Ctrl+Z 就回退一步。

4.4擦除 / 恢复画笔：手工修边

工具快捷键作用
🧽 擦除E把笔刷范围内的像素变成透明（中心彻底透明，边缘渐隐）
🖌 恢复R把擦掉的画回来（按原图恢复，不是涂颜色）
  • 笔刷大小 1 ~ 120 px，默认 24。精细修边就调到 2~5，放大到 40× 一点一点点。
  • 按住左键拖动可以连续涂，不必一下一下点。
  • 画布上会跟着光标显示两个圈（白圈 + 深色外圈），外圈就是实际作用范围。
标准修边顺序：魔棒抠大面积 → 擦除清掉残留的小色块 → 恢复补回被误抠的主体细节（发丝、指尖、箭头尖）→ 放大到 40× 检查一圈 → 再缩小看整体。

4.5抠掉浅色底：白底 / 浅粉底一次清空

适合：纯白、浅灰、浅粉、浅蓝的纯色背景（海报、贴纸、素材图最常见）。
不适合：风景照、渐变天空、主体本身也是白色的图（会把主体一起抠掉）。

参数范围 / 默认含义
亮度≥120 ~ 255，默认 205比这个更亮的像素才可能被抠掉
饱和≤0 ~ 120，默认 46颜色要够"淡"才可能被抠掉。右下角有 28 的过渡带，边缘不会一刀切
按钮抠掉浅色底整图范围一次性处理，不区分连通性

两个参数的配合逻辑：只抠"又亮又淡"的像素。所以白底上的黑色文字、彩色主体都安全； 但如果主体带白色描边，描边会和白底一起消失——这种图请改用魔棒，或者先抠完再用 🖌 恢复描边。

4.6一键精修边缘：去掉白边 / 粉边

抠完之后最常见的问题是边缘一圈发白、发粉的"雾边"。原因不是没抠干净，而是原图里这些半透明像素的颜色被背景色污染了。

参数范围 / 默认作用
去色边0 ~ 3，默认 1把半透明边缘像素的 RGB 换成邻近实心像素的平均色，同时保留透明度。这就是"去白边"的核心
羽化0 ~ 3，默认 1重新映射 alpha 曲线并做一次 3×3 平滑，让边缘从"硬切"变成 1~2px 的自然过渡
按钮一键精修边缘两个参数一起生效；都设为 0 就什么都不做

怎么选强度：白边很淡 → 去色边 1、羽化 1；白边明显（比如抠自深色文字旁）→ 去色边 2、羽化 1； 主体边缘本来就很锐利（像素画、图标）→ 羽化设 0，避免发糊。

精修会修改像素颜色（不只是透明度），所以它占一次撤销点，且不能靠"再点一次"回到原样。 处理前先 Ctrl+Z 之前的步骤确认好位置。

4.7裁切取景：只留要用的那一块

  1. 选 ✂️ 裁切（快捷键 C），在图上拖一个框。框外会压暗，框内显示三分线，右上角标着尺寸。
  2. 确认按 Enter，或点右侧「✓ 裁切到此区域」。画布只剩下框内的内容，原图的其他部分被丢弃（可撤销）。
  3. 想重来按 Esc 或点「取消」，框会消失，不影响图片。

还有一个更省事的按钮：「⬚ 自动裁到内容边界」——把四周所有全透明的空白自动裁掉。 抠完图先点它，图片就变成一个刚好包住主体的矩形，后面缩放到指针尺寸时主体会更大更清晰。

如果一张图里有好几个互不相连的元素（最典型的是"箭头 + 人物"这类素材图）， 点 「🧩 拆成独立元素」：工具会按连通块把它们各切一份，自动放进右侧「素材列表」， 碎点（很小的杂块）会被丢掉。之后你只要在列表里点一个元素 → 「✅ 用作指针画面」， 就只为这一个元素分配画布像素，而不是两个平分。

场景怎么选
图里只有主体 + 背景魔棒抠底 → 「自动裁到内容边界」
一张图里有 2 个以上不相连的元素抠底 → 「🧩 拆成独立元素」→ 素材列表里逐个用
元素相连（比如箭头压着人物的手）拆不开，用 ✂️ 手工框选
拆完为什么还要调画布？拆开只是"不再互相挤"，画布本身还是 64/128/256。 比如人物原图 678×702，塞进 64 只能是 62×64（脸剩 30 来像素，必糊）； 拆出来 + 画布 256，能到 247×256，脸有 100 多像素，这才是能用的清晰度。

4.8一键变清晰：放大 + 锐化

素材太小、太糊时用这个。它不是简单的"拉大"，而是做了三件事：

  1. 去噪（可关）：只平滑颜色接近的相邻像素，边缘不动，所以不会把细节糊掉；
  2. Lanczos3 重采样：比浏览器的双线性放大锐利得多，并且对透明边缘做了预乘处理，放大后不会出现黑边/灰晕；
  3. USM 锐化（非锐化蒙版）：按强度找回边缘对比，半透明处自动减半，避免出白边。
参数范围 / 默认怎么选
放大1× / 2× / 3× / 4×，默认 2×1× = 不放大，只去噪+锐化；小图标用 2~3×；4× 最清晰但也最慢
锐化0 ~ 200，默认 1000 = 只放大不锐化；120~150 适合线条图；超过 180 容易出现"描边感"
先去噪点默认勾选照片、视频截图、压缩过的 JPG 建议勾；干净的矢量图/像素画可以取消勾选

推荐组合

  • 表情包/截图糊了 → 2× + 锐化 100 + 去噪
  • 像素画要保留硬边 → 2× + 锐化 60 + 不去噪
  • 线稿/简笔画 → 3× + 锐化 140
  • 已经够大只想去毛边 → 1× + 锐化 80

两个限制

  • 放大后总像素超过 1200 万会直接拒绝（提示"目标太大"），请先裁切
  • 去噪只在 420 万像素以内执行，超过会自动跳过（只放大+锐化）

4.9AI 超分（🚀，可选）

「一键变清晰」是插值算法——它能把现有像素排布得更锐利，但变不出原图里没有的细节。 「🚀 AI 超分」是另一档东西：用神经网络（Real-ESRGAN）从训练数据里学到的纹理知识， 重建出小图里丢失的边缘、线条和质感。肉眼对比：插值放大是"更锐利的糊"，AI 超分是"真的多出细节"。

档位模型 / 倍率适合
Real-ESRGAN 4×realesr-general-x4v3，通用模型（约 5MB）绝大多数素材：插画、截图、照片、图标
轻量 CNN 2×WebSR 自研小网络（约 0.1MB）快档：图已经比较大、只差一点清晰度时用
三个前提要说清： ① 需要 Chrome / Edge 113 以上（WebGPU），不支持时按钮会明确报错而不是默默变慢； ② 首次使用需联网下载模型（之后不再需要，图片本身不离开电脑）； ③ 目标超过 2400 万像素会拒绝——先用 ✂️ 裁小或改 2× 档。
透明区域是怎么保住的？网络只认颜色不认透明度。工具把抠图前的原始画面喂给网络重建细节， 再把你的透明蒙版单独放大贴回去——所以抠掉的白底不会"复活"，半透明边缘也不会被网络糊掉。 超分后边缘若偏软，回到 ① 点一次「一键精修边缘」即可。
和 4.8 怎么选？两者在同一个卡片里：图源清晰、只是小 → AI 超分收益最大； 图源本身糊/有噪点 → 先「🪄 一键变清晰」去噪锐化，再考虑 AI 超分。 AI 超分结果的分辨率大（4×），放回 256 画布绰绰有余，指针在试戴里 1× 也会明显更干净。
处理时按钮会变成「⏳ 处理中…」，几十毫秒到一两秒不等，不要连点。处理完可以用 Ctrl+Z 回到处理前的尺寸与像素。

4.10标准尺寸：不管原图什么样，一键成标准图

做指针最常翻的车不是抠不干净，是尺寸不标准：素材 1080×720 的横图、竖图、带大片空白、长宽比 1.7:1…… 直接塞进画布要么被压扁，要么只剩中间一小块。这个按钮就是干这件事的：

📐 生成标准尺寸 做三步，一次完成：

  1. 裁掉四周空白——自动找到内容边界（同 4.7 的「自动裁到内容边界」）；
  2. 等比缩放到目标边长——宽的按宽贴边，高的按高贴边，绝不拉伸变形；
  3. 居中放进 N×N 正方形——缺的那一边补全透明，输出严格 N×N。
目标适用说明
32 / 48老系统、小屏能省体积，但细节基本没了——只适合极简图标
64兼容档所有 Windows 都认，但高分屏上会偏小偏糊
96折中常见系统指针的尺寸
128推荐清晰度和体积的平衡点。导出时还能同时打包多档尺寸，系统按 DPI 自动挑
256最大4K/高分屏最锐，但文件明显变大，部分系统只取前几档
裁空白等比缩放居中补透明严格 N×N

勾上 「生成后直接设为画布尺寸并用作指针画面」就是完整的一键路径：标准图 → 画布自动改成 N×N → 放进当前角色（角色栏上写着的那个）→ 顺手猜一个热点。 不勾则只生成标准图留在 ①，你可以先精修边缘再自己点「✅ 用作指针画面」。

为什么一定要正方形？Windows 的指针画布就是正方形位图，没有"宽指针"这回事。 你给一张 16:9 的图，系统只能等比缩进去 → 左右留白、主体变小；不缩就直接变形。 标准尺寸按钮做的就是这件事，只是替你算好了。
一个元素一张图。把箭头和人物塞进同一张 128 里，两个各分一半，等于每个都只有 64。 先用 4.7 的 🧩 拆成独立元素分开，再分别生成标准尺寸，给不同角色用——这才是"清晰"的正解。

4.11三个出口：直接拿去用

抠好之后不用切块、不用导出、不用再打开别的软件。顶部操作条右边有三个出口：

按钮做什么什么时候用

🎞 加入为帧把当前结果缩放成画布大小，作为一帧追加到动画里，跳到 ②做动画：换一张图 → 再点一次 → 重复

默认 64×64。如果你的图原本很大（比如 512×512 的立绘），缩小到 64 会丢细节，建议先在 ② 右侧「画布 → 尺寸」改成 128 或 256，再回 ① 点一次「用作指针画面」。

4.12精灵图切块（可选，做动画时很有用）

只有一种情况需要它：一张图里排了很多小图（精灵图、表情包九宫格、序列帧）。单张图抠完直接用作画面即可。

框选切块

勾上「框选松手即切」后，用左侧 ⬚（快捷键 S）拖一个框，松手就直接切好一块进「素材列表」。 不勾则需要拖框后按 Enter。 「行 × 列」> 1 时会在框内等分——比如框选一整排 4 个表情、设 1 行 4 列，一次得到 4 块。

整图网格分割

按格线切整张图。填「行 × 列」+ 四边距 + 格间距 + 内缩，点「▦ 整图网格分割」。 如果精灵图带金色/浅色格线，点 🔍 可以让工具自动识别格线位置并填好边距。

切出来的块出现在底部「素材」抽屉和右侧「素材列表」。点缩略图可以进入那一块继续抠图（左上角出现「↩ 回到整图」）， 右键或双击 = 直接设为指针画面。做完可以「🎞 全部块→帧」一次性变成动画。

4.13撤销与重做

  • Ctrl+Z 撤销、Ctrl+Y 重做，也可以用顶栏的「↩ / ↪」按钮。
  • 抠图模块保留 16 步 历史，设计模块保留 40 步。超出后最早的会被丢弃。
  • 会记入历史的有：魔棒、画笔、浅色底、精修、裁切、变清晰、切块、删除素材。
  • 「重置蒙版 ♻️」= 回到图片自身的透明状态（不是变成全不透明），带透明通道的 PNG 不会被洗白。

05 · ② 指针设计

这一模块决定指针最终长什么样、多大、点哪儿生效、要不要动。所有导出都以这里的内容为准。

5.1画布尺寸：先想清楚给谁看

指针画布是正方形。右侧「画布 → 尺寸」可选 16 / 24 / 32 / 48 / 64 / 96 / 128 / 256，默认 64。

尺寸适合说明
16 / 24 / 32怀旧、极简细节会丢光，只适合剪影类图形（箭头、圆点）
48 / 64日常首选64 是工具的默认值，多数显示器上清晰且文件小
96 / 128高分屏、精细图案带发丝、花纹、小字时用这个
256极限Windows 允许的最大值，文件最大，低分辨率屏上会被缩小
改尺寸会清空底图和全部动画帧（有确认弹窗）。所以顺序建议是：先在 ① 抠好图 → 到 ② 第一件事就是改尺寸 → 再点回 ①「用作指针画面」。 反过来（先做内容再改尺寸）会白做。

画布下面还有一个 像素风（最近邻缩放） 开关，只影响"缩放时怎么算像素"：

素材类型开关效果
像素画 / 游戏素材
Minecraft、FC、复古		勾上 缩放时直接取最近的像素，边缘保持硬朗，不会被平均成一团灰
照片 / 插画 / 截图不勾 缩小按面积平均、放大做插值，边缘过渡自然，不会出锯齿
放进去才发现糊？多半是画布太小。原图的短边 ≥ 96 时工具会主动问你要不要把画布升到 96/128； 已经放进去的图，改尺寸后要回 ① 重新点一次「用作指针画面」才生效（画布大小变了，旧内容不会自动重采样）。 另外：一张图里有两个元素（比如箭头 + 人物），别整张塞进 64px，用 ✂️ 裁切分开，各自做一个角色。

5.2图层：叠加与微调

指针画布由「底图 + 若干图层」合成。底图就是「用作指针画面」放进去的那张；图层用来加装饰、加字、加小标志。

操作怎么用

选中图层左侧 V（移动工具）→ 点画布上的图形，或点右面板图层列表
移动选中后直接拖。图层框是蓝色虚线

旋转右侧「旋转」滑杆 −180° ~ 180°
透明度右侧「不透明」5% ~ 100%
翻转 / 居中右侧 ⇋ ⇅ / 居中，作用于当前选中图层

并入底图把当前图层"拍平"进底图，之后不能再单独调，但可以减少运行时合成量

5.4热点：最容易做错的一步

热点 = 鼠标真正"点下去"的那个点。它决定了手感。做错的话指针图形是对的，但每次点击都偏半个图形，用起来极难受。

怎么设

  1. 选 📍 热点工具（快捷键 H），或直接点右面板「📍 画布点选」。
  2. 在画布上点一下正确的点。红色十字会立刻移过去，右面板「热点 X / Y」同步更新。
  3. 微调用右面板的 X / Y 数字框（范围 0 ~ 画布尺寸−1），或点「居中」「左上 0,0」快速归位。

该放在哪

  • 箭头类：箭尖（通常是图形左上方的那个尖）。
  • 手型 / 十字 / 文本 I 形：正中心。
  • 对称图形（圆、星、徽章）：正中心，或图形尖端（做装饰时）。
  • 带"指示方向"的图形：指示的那个尖端。
工具会自动猜一次：取"最上面一行不透明像素的平均 X"。箭头类基本准，其他形状请自己改。 右下预览窗里的红色小圈就是热点的实际位置，配合不同背景色看最直观。

5.5动画帧：让它动起来

多帧 = .ani 动画指针；只有 1 帧 = .cur 静态指针。

怎么加帧

  1. 做好一帧在画布上调到满意的状态。
  2. 保存成帧按 Enter，或点操作条「🎞 加入为帧」。底部托盘自动切到「帧」抽屉。
  3. 改一改再做下一帧移动图层、转一下、改个字……再按 Enter。
  4. 重复到满意为止。托盘里每一格就是一帧。

托盘里的操作

按钮作用
复制复制选中帧到它后面。做"只差一点点"的帧时最省事：复制 → 微调 → 覆盖本帧
删除删掉选中帧
← / →把选中帧往前/往后挪一位
反转整条动画倒序（做"来回摆动"时有用）
覆盖本帧用当前画布内容替换选中帧
载回画布把选中帧读回画布继续编辑（会清空当前图层）

时长→全部把当前这个 ms 值应用到所有帧

右下预览窗可以播放 / 暂停，缩放 1~4 倍，背景可选浅底 / 深底 / 棋盘——棋盘背景最适合检查透明边缘。

帧数别太多。3~8 帧足够；每多一帧，文件就大一圈，Windows 加载也慢。 做"呼吸感"用 2 帧 200ms 来回切就很自然。

5.6自动动画：不用手画，一键生成匹配动作

手画 8 帧太累，而且很容易"抖"。右面板「自动动画」卡片按动作预设直接算出来一组循环帧， 每帧都是一张完整的画布快照，生成后照样能逐帧改、能覆盖、能调时长。

动作默认效果与适合的角色
呼吸浮动8 帧 / 90ms上下浮动 2% 画布高度，最通用。箭头、十字、I 形都稳
呼吸缩放8 帧 / 90ms绕中心 96%~100% 轻微缩放，比浮动更"活"
旋转12 帧 / 90ms整圈匀速转，忙碌（Wait）的经典做法
弹跳8 帧 / 90ms上下弹跳 + 落地压扁，后台运行（AppStarting）很合适
摇摆8 帧 / 90ms绕底部 ±5° 摇晃，人物/手型类素材最自然
光晕脉冲8 帧 / 90ms取素材自己的主色做外发光，强度呼吸。适合"帮助"、强调态
明暗呼吸8 帧 / 90ms整图不透明度 60%~100% 呼吸，做小沙漏/后台标记很讨巧

切到某个角色时，动作下拉会自动选到推荐预设，卡片底下那行提示也会写清理由（比如「当前角色『忙碌』建议：旋转」）。

参数范围 / 默认怎么调
帧数4 ~ 16，默认 8旋转建议 12 帧才顺；呼吸类 6~8 帧够了。帧越多文件越大
每帧时长50 ~ 150ms，默认 90数字越小转得越快。整圈 12 帧 × 90ms ≈ 1.08 秒一圈
幅度30 ~ 200，默认 100动作大小。指针本身很小，幅度大了会显得"抽"，100 通常就够
生成后还能改。自动动画只是"填好一堆帧"，帧托盘照常可用：选中某帧 → 改画布 → 「覆盖本帧」， 或「复制」后微调。想加一点手绘细节（比如眨个眼），就在生成结果上改两帧。
只有多帧才导出 .ani。生成后至少保留 2 帧，否则这个角色会导出成静态 .cur（动画自然消失）。 另外：热点位置不随动画移动，浮动/摇摆类动作的"位移"只是视觉，点击点始终在同一个像素上。
动画帧的封装格式参考了 damieng/Anim8Cursor 的 .ani 帧结构（每帧含独立热点 + rate 块）， 预设动作本身是工具里用 Canvas 变换实时算的，不依赖外部服务。

5.717 个指针角色：每个角色一份独立作品

Windows 的指针不是一张图，是 17 个"角色"（正常箭头、忙碌、文本 I 形、手型……）。 以前的工具是一份作品通吃 17 个角色，做着做着就糊涂了：我这一笔是画给谁的？

    1. 点顶栏 👁 试戴。没有作品时会提示先回 ① 抠图；有作品就直接进桌面。

    3. 看红色十字。它标的是热点——也就是系统认为你"点下去"的那个像素。 如果十字落在图案左上角、而你想让它落在笔尖或箭头尖上，回 ② 用 H 键重设热点。
    4. 多帧作品会自动循环播放，帧率就是你在底部调的每帧毫秒数，不用手动点播放。

    上排四个开关分别管什么

    控件作用
    尺寸32 / 48 / 64 / 96 / 128 px。选 32 看小尺寸糊不糊，选 96 看大尺寸细节够不够。
    放大1× 是真实大小；2× / 3× 只是放大观察，窗口里会标注"放大显示"，不代表实际会变大。
    场景桌面（深色壁纸 + 图标）、文档（白底）、深色（暗色界面）、棋盘（透明区可见）。 浅色图案在深色场景里最容易被看出白边，深色图案在文档场景里最容易看出毛边。
    热点关掉红色十字，只留一个小圆点，适合看整体效果时用。
    示范鼠标不进去时，指针会自己沿路径走一圈（正文 → 按钮 → 右下角 → 右边缘）， 用来快速看完整套角色切换。

    下面一排是角色胶囊：默认选中 🎯 自动，按位置自动切换； 点任意一个角色（比如"忙碌"）就锁定成那个角色，方便单独看它在深色和浅色背景上的效果。 锁定后鼠标怎么移都不变，点回「自动」才恢复。

    两个常见误区。一是别在 1× 下判断清晰度——32px 的指针本来就只有指甲盖大小， 看着糊是正常的，真正要判断的是"在 2× 下边缘有没有白边、热点有没有偏"。 二是试戴不能替代导出后实装：Windows 在不同缩放比例（100% / 125% / 150%）下会自己挑不同尺寸， 试戴看到的是"像素本身"，实装还要看系统怎么缩放。

    6.1导出对话框

    点右上「📦 导出皮肤」打开。需要填/确认的只有四项：

    字段默认说明
    皮肤名称= 顶栏作品名会出现在「鼠标属性 → 指针 → 方案」下拉里，也用作文件夹名。建议用中文短名，别带 \ / : * ? " < > |
    指针尺寸= 当前画布.ani 动画帧的尺寸（32/48/64/96/128/256）。静态 .cur 不用这个，用下面的多尺寸
    .cur 多尺寸48 / 64 / 96一个 .cur 文件里打包多个尺寸，Windows 按当前 DPI 自动挑。全不勾时回落到 48/64/96；画布比勾选的大时会自动补一档，不白丢清晰度
    角色表17 行分别是「单独制作 / 沿用当前作品 / ✔ 外部文件」三列按钮：去编辑（关面板直接切到那个角色的画布）、换文件（用你自己的 .cur/.ani 顶替）、恢复（清掉外部文件）

    对话框底部四个按钮：导出 CUR（只导一个静态指针文件）、导出 ANI（只导一个动画文件）、 导出 INF（只导一个 Install.inf）、导出 ZIP（推荐）——一次给齐所有文件 + 脚本 + 说明。

    17 个角色是怎么出的？按顺序判断：① 你给这一行指定了外部文件 → 用外部文件； ② 这个角色在 ② 里单独做过（角色栏有绿点）→ 用它自己那份，多帧就出 .ani、单帧出 .cur； ③ 都没做 → 沿用你当前正在编辑的那一份。所以"只做一个箭头"也能导出完整皮肤，不会缺角色。

    6.2ZIP 里到底有什么

    文件作用
    17 个 .cur / .ani每个指针角色一个文件，文件名固定（pointer / work / busy / hand …）
    Install.inf方案定义。声明"把这些文件复制到 Cursors\皮肤名\，并在 Schemes 下注册一个叫皮肤名的方案"
    安装皮肤.bat申请管理员 → 复制文件 → 注册方案。装完才有得选
    立即启用.bat不用打开控制面板，直接写注册表并通知系统刷新（想立刻看到效果就用它）
    卸载皮肤.bat只删自己那一项方案和文件夹
    恢复默认指针.bat把当前指针切回 Windows 默认方案
    立即生效.ps1 / 恢复默认.ps1上面两个 bat 调用的 PowerShell 脚本（调用系统 API 立即刷新，不重启资源管理器）
    说明.txt角色 ↔ 文件名对照表，方便以后手动改

    6.3安装（三步）

    1. 解压 ZIP到任意位置（桌面、下载都行）。不要只把 bat 拖出来单独运行，它需要旁边的指针文件和 INF。
    2. 双击「安装皮肤.bat」。会弹 UAC 问是否允许管理员权限，点「是」。 看到「完成」后按任意键关闭窗口。
    3. 应用打开「控制面板 → 鼠标（或 设置 → 蓝牙和其他设备 → 鼠标 → 其他鼠标设置）→ 指针」， 在「方案」下拉里选你的皮肤名 → 点 应用 → 确定。
    懒得进控制面板：直接双击「立即启用.bat」，它会把注册表写好并让系统立刻刷新，鼠标当场变。之后方案下拉里同样能看到你这一项。

    装完想改 / 想撤

    想要做法
    切回系统默认外观双击「恢复默认指针.bat」，或方案里选「Windows 默认」
    彻底删掉这套皮肤双击「卸载皮肤.bat」（删方案项 + 删文件夹）。建议先切回默认再卸载
    改了一版重新装再跑一次「安装皮肤.bat」会覆盖同名文件夹，然后「立即启用.bat」
    只换某一个角色把新文件按「说明.txt」里的名字（如 work.ani）覆盖进 C:\Windows\Cursors\皮肤名\，再点「立即启用.bat」

    6.4为什么它不会弄坏系统

    • 导出的指针文件放在 C:\Windows\Cursors\你的皮肤名\ 这个独立文件夹里，不覆盖任何系统文件。
    • 注册表只往 HKCU\Control Panel\Cursors\Schemes 下新增一个键值，不动 Aero 系列的 17 个默认项。
    • 所以「鼠标属性」里看到的仍然是：Windows 默认、Windows 黑、Windows 反转……+ 你的皮肤名。随时可以切走、切回。
    • 安装脚本里做了一件小事：先把文件复制到临时目录再调系统安装接口。原因是 INF 安装路径含中文时容易失败，这样绕开了。

    08 · 常见问题 FAQ

    Q1　双击 HTML 打开是白屏 / 一堆代码

    被系统用错程序打开了。右键文件 → 打开方式 → Microsoft Edge（或 Chrome）。 如果仍然白屏，检查是不是把文件放在了网盘同步目录且尚未下载完整；也可以用 edge://version 确认浏览器版本 ≥ 88。

    Q2　魔棒点了半天没反应

    按这个顺序看：① 左侧 🪄 是否高亮（点到了别处就会用别的工具）；② 容差是不是被拖到个位数； ③ 这块是不是已经抠过了（棋盘格处再点不会有变化）；④ 是不是选了「全图」但背景颜色跨度很大——换回「连通」。 最保险的做法：先按 Ctrl+Z 退回干净状态，容差调到 45 再点一次。

    Q3　抠完边缘有一圈白边 / 粉边

    不是没抠干净，是原图边缘像素的颜色被背景污染了。用右侧「批量去背 / 边缘精修」里的 去色边 1~2 + 羽化 1，点「一键精修边缘」即可。白边特别重时把去色边调到 3。

    Q4　「一键变清晰」点了没反应 / 提示目标太大

    提示"目标太大"说明放大后超过 1200 万像素：先用 ✂️ 裁切掉不需要的部分，或把放大倍数从 4× 降到 2×。 如果只是"看起来变化不大"，把锐化从 100 调到 150 试试；纯色块图形放大后本来就没什么可锐化的。

    Q5　点「用作指针画面」之后图变小了很多，看着糊

    因为画布默认只有 64×64。去 ② 右侧「画布 → 尺寸」改成 128 或 256，然后回 ① 再点一次「用作指针画面」。 顺序不能反：改尺寸会清空已有内容。

    Q6　装完皮肤，鼠标没变

    三件事依次确认：① 安装皮肤.bat 有没有真的以管理员身份跑完（窗口里应该有"完成"）； ② 「鼠标属性 → 指针 → 方案」里选中你的皮肤名后有没有点 应用；③ 把鼠标移到桌面上移动一下。 都做了还不变，直接双击 立即启用.bat，它会绕过控制面板直接写注册表。

    Q7　方案下拉里找不到我的皮肤名

    说明注册没成功。把已经打开的鼠标属性窗口关掉重新打开（它只在打开时读一次列表）。 仍然没有就重跑 安装皮肤.bat，注意别把 bat 单独拖出来运行——它要和 Install.inf 在同一目录。

    Q8　动画不动，还是静态的

    只有帧数 ≥ 2 才会导出 .ani。检查底部托盘「帧」抽屉里是不是真的有多帧； 另外 Windows 只在部分角色上播放动画（忙碌、后台运行、候选选择），"正常选择"箭头通常不播动画——这是系统行为，不是皮肤坏了。

    Q9　指针太大 / 太小

    「设置 → 辅助功能 → 鼠标指针和触控」里的"大小"是另一套机制（整体放大系统指针），和皮肤方案是两回事。 皮肤本身的视觉大小由文件里的图形占比决定：在 ② 里把图形缩小留白、或把画布尺寸调大再放图，都会让指针显得更小。

    Q10　能保存工程吗？下次还能改吗

    目前没有工程文件。关掉页面 = 内容丢失。建议：原始大图另存一份；导出 ZIP 留着（里面的 17 个文件本身就是成品）； 想继续改就把导出的 .cur/.ani 拖回窗口，工具会把它读进 ② 让你接着编辑。

    Q11　会把我上传的图传到服务器吗

    不会。整个工具就是一个离线 HTML，所有计算都在你自己的浏览器里，断网也能用。可以打开开发者工具的 Network 面板验证：没有任何请求。

    Q12　做的指针能商用 / 会侵权吗

    工具本身不限制用途。但素材版权由你自己负责：用官方立绘、明星照片、影视截图做皮肤并分发，属于二次使用他人作品， 请自行确认授权范围。自己画的、买的商用素材、明确开源许可的图都没有这个问题。

    Q13　② 里放大后为什么那么糊？像素一块块的

    因为画布小，不是显示出了问题。画布默认 64×64，在 ② 里放大到 6～7 倍显示， 一个"方格"就是一个设计像素；图里挤了两个元素时，每个只分到 30 来个像素， 再怎么放大也长不出细节。判断标准是导出后 1:1 看（或试戴里用 1×），不是看放大后的画布。

    三条对策，按效果排序：

    1. 放大画布：右侧「画布 → 尺寸」改 128（素材够精细就 256），然后回 ① 重新点一次「用作指针画面」—— 改尺寸会清空内容，旧图不会自动变清晰。原图短边 ≥ 96 时工具也会主动问你要不要升级。
    2. 一个元素一个角色：箭头和人像别挤在一张 64px 图里。 抠完底直接点 「🧩 拆成独立元素」，工具会按连通块各切一份放进素材列表， 再逐个「用作指针画面」。现在每个角色是独立作品：画完箭头点角色栏切到「个人选择」， 做人物，两份互不覆盖；导出时各出各的文件。 （元素粘在一起拆不开时，改用 ✂️ 手工框选，或「精灵图切块」。）
    3. 像素画勾「像素风」：勾上后缩放走最近邻，边缘保持硬块；不勾则按面积平均，适合照片插画。 勾错方向会让边缘变脏或变糊。

    另外，「一键变清晰」是插值 + 锐化，不能凭空长出细节；在 ① 里放大到 2× 再塞回 64px 画布，等于白做。

    算一下就明白了：一张 1244×732 的素材图，整张塞进 64px 画布 = 缩小 19 倍， 右边的箭头只剩 21×29、人物只剩 35×36——脸只有 30 多个像素，再放大当然是一团。 同一个箭头单独放进 256px 画布是 188×256，人物单独放是 247×256，这才对得上"原图很清晰"。

    Q14　怎么知道我现在做的是 17 个角色里的哪一个？切来切去会不会丢东西

    看三处，任选一处都够：画布上方的角色栏（写着「正在编辑 正常选择 · Arrow → pointer.cur」）、 顶栏标签页（② 指针设计 · 忙碌）、右面板第一张卡片（大号角色名 + 状态）。

    不会丢。切换角色时工具会先把你手上这份的画布、图层、全部帧、热点存进该角色名下，再载入目标角色的那份； 切回来一模一样。角色栏里带绿点的就是已经有作品的角色。

    唯一要注意：撤销历史是按角色分开的，切过去之后 Ctrl+Z 撤不回上一个角色的操作。

    Q15　自动动画会不会把别的角色搞乱？想只改其中一帧怎么办

    不会。动画帧属于当前角色，生成只替换这个角色的帧，其他角色完全不受影响。

    想微调：底部托盘切到「帧」抽屉 → 点某一帧 → 在画布上改 → 点「覆盖本帧」； 或者选中帧点「复制」再改。每帧的 ms 也能单独改（「本帧 __ ms」和「时长→全部」）。

    只有 1 帧会导出成静态 .cur；想要 .ani 动画至少留 2 帧。

    09 · 限制与已知问题

    限制说明 / 绕法
    最大 256×256Windows 指针格式的硬上限，无法突破。想要"更大"只能让图形本身占满画布
    只有 Windows 格式输出 .cur / .ani。macOS 用不了（它要 .cape 或第三方工具）
    没有工程保存见 FAQ Q10。重要作品请及时导出 ZIP
    AI 超分有前提「🚀 AI 超分」走开源 WebSR + Real-ESRGAN，需要 Chrome / Edge 113+（WebGPU）且首次联网下载模型；不满足时只能用本地 Lanczos + USM（那条路径不联网、但不会"长"出新细节）
    AI 超分是"重建"模型会按训练数据补细节，极端放大的局部可能有小面积"猜"的痕迹。定稿前建议放大看一眼
    硬边有轻微振铃Lanczos3 在纯硬边（如方形色块）的 alpha 上会有约 8% 的过冲，表现为边缘一像素的浅色描边。人眼基本不可见，介意的话改用 2× + 锐化 60
    大图处理会被限流放大后 > 1200 万像素直接拒绝；去噪 > 420 万像素自动跳过。低配机器上请先裁切
    一次只处理一张图拖多张只会保留最后一张。批量做请一张一张来
    企业策略可能拦截部分公司的组策略禁止修改指针方案，或禁止运行 bat。这种情况下装不上，需要联系 IT
    浏览器要求需要支持 Canvas / ES2020 的浏览器：Edge 88+、Chrome 88+。不保证在套壳浏览器里正常

    术语表

    词意思
    .curWindows 静态指针文件格式。本质是带"热点坐标"的图标文件，内含 1 个或多个尺寸
    .aniWindows 动画指针格式。由多帧 .cur + 每帧停留时间组成
    热点 / Hotspot指针图里"真正点下去"的那个像素坐标。不是图形中心，而是你希望点击生效的点
    角色 / Scheme SlotWindows 定义的 17 种指针状态（箭头、忙碌、文本……），一套方案要配齐 17 个
    INFWindows 的安装信息文件。本项目用它"注册一个新指针方案"，而不是覆盖系统值
    蒙版 / Mask每个像素的透明度（0 = 全透明）。魔棒、画笔、浅底抠除改的都是它
    预乘 alpha把 RGB 先乘上透明度再插值，避免透明边缘放大后出现黑边。变清晰功能内部使用
    Lanczos3一种高质量重采样核函数，比双线性/双三次更锐利，是 pica 等库的默认高质量选项
    角色（slot）Windows 指针方案里的 17 个位置，每个位置对应一个注册表项和一个文件（pointer / work / busy …）
    标准尺寸裁掉空白 + 等比缩放 + 居中补透明后的严格 N×N 正方形图，N 常用 128
    USM / 非锐化蒙版经典锐化算法：原图减去模糊层得到"边缘细节"，再按强度加回原图
