01 · 它是什么 / 能做什么

指针工坊是一个单文件网页工具：用浏览器打开 指针工坊.html 就能用，不需要安装、不需要联网、不上传图片。 它把「做一套鼠标指针」这件事拆成三段，串在一个界面里：

① 抠图 / 素材

把海报、截图、立绘里的主体抠出来：魔棒、画笔修边、去浅底、去白边、裁切、一键变清晰。

② 指针设计

定尺寸、摆图层、补画细节、设热点（点哪儿生效）、做多帧动画。

③ 导出皮肤

打成 ZIP：17 个角色的 .cur/.ani + Install.inf + 安装脚本，双击即装。

能做到这些

  • 17 个指针角色一次配齐：正常箭头、忙碌、文本 I 形、手型链接、调整大小、移动、不可用…… 每个角色一份独立作品，切角色自动存档，导出时各出各的文件；没做的角色自动沿用当前这份。
  • 一键标准尺寸：不管素材是横图、竖图还是长宽比奇怪，一键裁空白 → 等比缩放 → 居中补透明，输出严格 128×128（也可选 32/48/64/96/256）。
  • 自动动画：旋转、弹跳、摇摆、呼吸、光晕脉冲等 7 种预设，一键生成 4~16 帧循环动画，还会按角色推荐动作（忙碌 → 旋转）。
  • 静态指针（.cur）和动画指针（.ani）：多帧就是动画，帧数和每帧毫秒数随便调，内置播放预览。
  • 多尺寸打包：一次导出 48/64/96 等多个尺寸，高分屏自动挑最清晰的那一档。
  • 不破坏系统：装完只是「鼠标属性 → 指针 → 方案」里多了一项，系统自带的 Aero 指针一个字节都不动。

不能做到这些（提前说清楚）

  • 不能做 macOS / Linux 指针——输出格式是 Windows 的 .cur / .ani。
  • 「🪄 一键变清晰」是插值放大 + 锐化（本地、免联网），不会无中生有；想要"重建细节"用旁边需要 WebGPU 的 🚀 AI 超分。
  • 没有「工程文件」保存功能。关掉页面前请把导出 ZIP 存好，原始大图另存一份（详见 限制说明）。
  • 不能超过 256×256：这是 Windows 指针的硬上限。
建议用 Edge 或 Chrome 打开。IE 和部分国产双核浏览器的「兼容模式」不支持本项目用到的画布 API，会白屏。 如果双击被系统用别的程序打开，右键 → 打开方式 → Microsoft Edge。

02 · 一分钟上手

只想最快做出一套能用的指针，照这 5 步走，全程约 3 分钟：

  1. 把图片拖进窗口打开后自动进入「① 抠图 / 素材」，画布上显示整张图。
  2. 点背景左侧 🪄 魔棒已默认选中，直接点图片的背景区域，同色背景会变成棋盘格（= 透明）。点不干净就把右侧「魔棒容差」往上调，再点没抠掉的地方。
  3. 点「📐 生成标准尺寸」（右侧「标准尺寸」卡片，默认 128）。它会裁掉四周空白、等比缩放、居中补透明， 一步得到严格 128×128，并顺手放进当前角色的画布、猜个热点、跳到「② 指针设计」。 想手动控制就改目标尺寸，或取消勾选后用「✅ 用作指针画面」。
  4. 确认热点画布上的红色十字就是"点下去"的位置。位置不对就在左侧点 📍，再在画布上点一下正确的点（箭头类通常是画布左上方的尖）。
  5. 导出并安装右上「📦 导出皮肤」→ 填皮肤名 → 「导出 ZIP」→ 解压 → 双击 安装皮肤.bat → 打开「鼠标属性 → 指针 → 方案」，选你的皮肤名 → 应用。
第 5 步的「应用」别漏。装完皮肤后，方案列表里会出现你的皮肤名，但必须点一次「应用」（或「确定」）才会真正生效； 部分系统还需要把鼠标移到桌面上晃一下才刷新。
装之前想先看看？第 4 步之后随时点顶栏 👁 试戴：会在模拟桌面上按真实尺寸预览， 鼠标移到正文/按钮/窗口边上会自动切换成对应角色，多帧作品还会循环播放。详见 5.8 实景试戴。

03 · 界面总览

整个界面是「顶栏 + 左侧工具条 + 中间画布 + 右侧参数面板 + 底部托盘」的五区结构，两条灰色分隔条可以拖动改大小； 切到 ② 时画布上方还会多出一条角色栏，随时告诉你正在编辑 17 个角色里的哪一个。

编号区域作用
6顶栏切换 ①② 两个模块、填作品名、打开图片、导入已有 .cur/.ani、撤销/重做、👁 试戴（实景预览）、导出皮肤
7角色栏（仅 ② 模块）画布正上方一条浅蓝横栏，写着「正在编辑 · 正常选择 / Arrow → pointer.cur」，右边 17 个角色胶囊可切换。右上「全部 17 个 ↗」直接打开导出面板看总览
1顶部操作条当前模块最主要的动作。① 里是「用作指针画面 / 加入为帧」，② 里是颜色、笔粗、字号、加入为帧、插入图片
2左侧工具条当前可用的工具。高亮的那一个是选中状态，点一下切换
3画布抠图和设计都在这里。滚轮缩放（以光标为中心，最高 40×），按住空格 或中键拖动平移
4右侧参数面板按卡片分组：工具参数、精修、变清晰、切块、素材列表（①）／画布、图层、属性、热点（②）
5底部托盘「素材」和「帧」两个抽屉，点抽屉名切换。右边固定是预览窗，可播放动画、换背景
7缩放条−／＋、适应窗口、1:1（原始像素）。40× 时画布上会出现像素网格，方便一像素一像素修边

把界面调成你习惯的样子

  • 拖动分隔条：画布与右面板之间的竖条左右拖（右面板 190~520px），底托盘上方的横条上下拖（96~420px）。
  • 收起面板：操作条右端的 ⇥ 收起右面板、⇩ 收起底部托盘，画布会立刻变大。
  • 窗口越大越好用：1080p 以上屏幕建议最大化浏览器，抠图时看得更清。
改过布局后不用记，工具不保存界面状态，下次打开会回到默认（右面板 300px、托盘 164px）。
