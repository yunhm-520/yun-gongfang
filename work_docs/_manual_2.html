04 · ① 抠图 / 素材

这一模块只干一件事：把你要的那块图干净地抠出来。抠完点「✅ 用作指针画面」就走人，不需要再切块、也不需要导出中间文件。

4.1打开图片

四种方式，任选一种：

方式说明
拖进窗口从资源管理器直接拖图片到页面任意位置。支持 PNG / JPG / WebP / GIF（GIF 只取第一帧）
Ctrl+V 粘贴截图后直接在页面里粘贴，最快。QQ/微信截图 → Ctrl+V 即可
「📂 打开图片」顶栏按钮，走文件选择框
拖入 .cur / .ani不是打开图片，而是把现成的指针载入 ② 设计模块去改（标题栏会变成文件名）
一次只拖一张图。同时拖进多张时，最终只会留下最后加载完的那一张。要处理第二张，等第一张做完（已点「用作指针画面」）再拖。

图片多大都行，工具内部按原始像素处理。但要注意：最后做指针时会被缩放到 256 以内， 所以抠图阶段没必要对一张 4000px 的海报精雕细琢——真正决定清晰度的是「缩小到 64 之前有没有先做去噪/锐化」。

4.2视图操作（抠图精度的前提）

操作效果
滚轮以光标为中心缩放，0.05× ~ 40×。放大到 12× 以上会出现像素网格
按住 空格 拖动 / 中键拖动平移画面
右下 适应 / 1:1整图完整显示 / 一个屏幕像素对应一个图片像素
左侧 ✋抓手工具（不按空格也能拖）
修边请一定放大到 20~40×。在 100% 视图下看着"干净"的边缘，缩到 32×32 之后往往是一圈脏点； 反过来，放大到 40× 修一遍，缩到小尺寸就干净得多。

4.3魔棒：点一下就抠掉一片

左侧 🪄（快捷键 W）是默认工具。在图片上点一下，与点击处颜色相近、并且相连的整片区域会变透明（棋盘格）。

三个参数

参数范围 / 默认怎么调
魔棒容差1 ~ 100，默认 30决定"多不像才算不同色"。背景是纯色但略有噪点时用 40~60；背景本身有渐变时可用 70+，但要小心把主体也吃掉
取样：连通默认只抠和点击点连在一起的那一片。适合"主体被背景包住"的情况
取样：全图—整张图里所有相近颜色都抠掉，不管连不连。适合"背景和主体间有白边隔开"或"多处同色背景"

点击时的三个动作

操作效果
单击抠掉这一片（把透明度的"不透明"往下压）
Shift + 单击继续抠另一片。效果与单击相同，只是习惯上用它来表示"接着来"
Alt + 单击撤回：把这一片按同样的颜色范围恢复到不透明。抠多了就用它救回来，比按 Ctrl+Z 更精准
点了没反应？按顺序排查：
  1. 左侧工具条上 🪄 是否高亮——如果高亮的是 ✂️ 或 🧽，点击当然不是抠图；
  2. 容差是不是被拖到了 1~5（几乎只能点中完全相同的颜色）；
  3. 你是不是点了「取样：全图」但背景颜色跨度很大——换回"连通"再点；
  4. 这一片是不是已经被抠过了（棋盘格处再点是不会有变化的）。

一次抠不干净怎么办

用分层推进：先用容差 30 点掉最纯的那片 → 调到 45 点剩下的过渡区 → 调到 60 点角落的阴影。 每次点击都是一次独立的撤销点，抠坏了 Ctrl+Z 就回退一步。

4.4擦除 / 恢复画笔：手工修边

工具快捷键作用
🧽 擦除E把笔刷范围内的像素变成透明（中心彻底透明，边缘渐隐）
🖌 恢复R把擦掉的画回来（按原图恢复，不是涂颜色）
  • 笔刷大小 1 ~ 120 px，默认 24。精细修边就调到 2~5，放大到 40× 一点一点点。
  • 按住左键拖动可以连续涂，不必一下一下点。
  • 画布上会跟着光标显示两个圈（白圈 + 深色外圈），外圈就是实际作用范围。
标准修边顺序：魔棒抠大面积 → 擦除清掉残留的小色块 → 恢复补回被误抠的主体细节（发丝、指尖、箭头尖）→ 放大到 40× 检查一圈 → 再缩小看整体。

4.5抠掉浅色底：白底 / 浅粉底一次清空

适合：纯白、浅灰、浅粉、浅蓝的纯色背景（海报、贴纸、素材图最常见）。
不适合：风景照、渐变天空、主体本身也是白色的图（会把主体一起抠掉）。

参数范围 / 默认含义
亮度≥120 ~ 255，默认 205比这个更亮的像素才可能被抠掉
饱和≤0 ~ 120，默认 46颜色要够"淡"才可能被抠掉。右下角有 28 的过渡带，边缘不会一刀切
按钮抠掉浅色底整图范围一次性处理，不区分连通性

两个参数的配合逻辑：只抠"又亮又淡"的像素。所以白底上的黑色文字、彩色主体都安全； 但如果主体带白色描边，描边会和白底一起消失——这种图请改用魔棒，或者先抠完再用 🖌 恢复描边。

4.6一键精修边缘：去掉白边 / 粉边

抠完之后最常见的问题是边缘一圈发白、发粉的"雾边"。原因不是没抠干净，而是原图里这些半透明像素的颜色被背景色污染了。

参数范围 / 默认作用
去色边0 ~ 3，默认 1把半透明边缘像素的 RGB 换成邻近实心像素的平均色，同时保留透明度。这就是"去白边"的核心
羽化0 ~ 3，默认 1重新映射 alpha 曲线并做一次 3×3 平滑，让边缘从"硬切"变成 1~2px 的自然过渡
按钮一键精修边缘两个参数一起生效；都设为 0 就什么都不做

怎么选强度：白边很淡 → 去色边 1、羽化 1；白边明显（比如抠自深色文字旁）→ 去色边 2、羽化 1； 主体边缘本来就很锐利（像素画、图标）→ 羽化设 0，避免发糊。

精修会修改像素颜色（不只是透明度），所以它占一次撤销点，且不能靠"再点一次"回到原样。 处理前先 Ctrl+Z 之前的步骤确认好位置。

4.7裁切取景：只留要用的那一块

  1. 选 ✂️ 裁切（快捷键 C），在图上拖一个框。框外会压暗，框内显示三分线，右上角标着尺寸。
  2. 确认按 Enter，或点右侧「✓ 裁切到此区域」。画布只剩下框内的内容，原图的其他部分被丢弃（可撤销）。
  3. 想重来按 Esc 或点「取消」，框会消失，不影响图片。

还有一个更省事的按钮：「⬚ 自动裁到内容边界」——把四周所有全透明的空白自动裁掉。 抠完图先点它，图片就变成一个刚好包住主体的矩形，后面缩放到指针尺寸时主体会更大更清晰。

如果一张图里有好几个互不相连的元素（最典型的是"箭头 + 人物"这类素材图）， 点 「🧩 拆成独立元素」：工具会按连通块把它们各切一份，自动放进右侧「素材列表」， 碎点（很小的杂块）会被丢掉。之后你只要在列表里点一个元素 → 「✅ 用作指针画面」， 就只为这一个元素分配画布像素，而不是两个平分。

场景怎么选
图里只有主体 + 背景魔棒抠底 → 「自动裁到内容边界」
一张图里有 2 个以上不相连的元素抠底 → 「🧩 拆成独立元素」→ 素材列表里逐个用
元素相连（比如箭头压着人物的手）拆不开，用 ✂️ 手工框选
拆完为什么还要调画布？拆开只是"不再互相挤"，画布本身还是 64/128/256。 比如人物原图 678×702，塞进 64 只能是 62×64（脸剩 30 来像素，必糊）； 拆出来 + 画布 256，能到 247×256，脸有 100 多像素，这才是能用的清晰度。

4.8一键变清晰：放大 + 锐化

素材太小、太糊时用这个。它不是简单的"拉大"，而是做了三件事：

  1. 去噪（可关）：只平滑颜色接近的相邻像素，边缘不动，所以不会把细节糊掉；
  2. Lanczos3 重采样：比浏览器的双线性放大锐利得多，并且对透明边缘做了预乘处理，放大后不会出现黑边/灰晕；
  3. USM 锐化（非锐化蒙版）：按强度找回边缘对比，半透明处自动减半，避免出白边。
参数范围 / 默认怎么选
放大1× / 2× / 3× / 4×，默认 2×1× = 不放大，只去噪+锐化；小图标用 2~3×；4× 最清晰但也最慢
锐化0 ~ 200，默认 1000 = 只放大不锐化；120~150 适合线条图；超过 180 容易出现"描边感"
先去噪点默认勾选照片、视频截图、压缩过的 JPG 建议勾；干净的矢量图/像素画可以取消勾选

推荐组合

  • 表情包/截图糊了 → 2× + 锐化 100 + 去噪
  • 像素画要保留硬边 → 2× + 锐化 60 + 不去噪
  • 线稿/简笔画 → 3× + 锐化 140
  • 已经够大只想去毛边 → 1× + 锐化 80

两个限制

  • 放大后总像素超过 1200 万会直接拒绝（提示"目标太大"），请先裁切
  • 去噪只在 420 万像素以内执行，超过会自动跳过（只放大+锐化）

4.9AI 超分（🚀，可选）

「一键变清晰」是插值算法——它能把现有像素排布得更锐利，但变不出原图里没有的细节。 「🚀 AI 超分」是另一档东西：用神经网络（Real-ESRGAN）从训练数据里学到的纹理知识， 重建出小图里丢失的边缘、线条和质感。肉眼对比：插值放大是"更锐利的糊"，AI 超分是"真的多出细节"。

档位模型 / 倍率适合
Real-ESRGAN 4×realesr-general-x4v3，通用模型（约 5MB）绝大多数素材：插画、截图、照片、图标
轻量 CNN 2×WebSR 自研小网络（约 0.1MB）快档：图已经比较大、只差一点清晰度时用
三个前提要说清： ① 需要 Chrome / Edge 113 以上（WebGPU），不支持时按钮会明确报错而不是默默变慢； ② 首次使用需联网下载模型（之后不再需要，图片本身不离开电脑）； ③ 目标超过 2400 万像素会拒绝——先用 ✂️ 裁小或改 2× 档。
透明区域是怎么保住的？网络只认颜色不认透明度。工具把抠图前的原始画面喂给网络重建细节， 再把你的透明蒙版单独放大贴回去——所以抠掉的白底不会"复活"，半透明边缘也不会被网络糊掉。 超分后边缘若偏软，回到 ① 点一次「一键精修边缘」即可。
和 4.8 怎么选？两者在同一个卡片里：图源清晰、只是小 → AI 超分收益最大； 图源本身糊/有噪点 → 先「🪄 一键变清晰」去噪锐化，再考虑 AI 超分。 AI 超分结果的分辨率大（4×），放回 256 画布绰绰有余，指针在试戴里 1× 也会明显更干净。
处理时按钮会变成「⏳ 处理中…」，几十毫秒到一两秒不等，不要连点。处理完可以用 Ctrl+Z 回到处理前的尺寸与像素。

4.10标准尺寸：不管原图什么样，一键成标准图

做指针最常翻的车不是抠不干净，是尺寸不标准：素材 1080×720 的横图、竖图、带大片空白、长宽比 1.7:1…… 直接塞进画布要么被压扁，要么只剩中间一小块。这个按钮就是干这件事的：

📐 生成标准尺寸 做三步，一次完成：

  1. 裁掉四周空白——自动找到内容边界（同 4.7 的「自动裁到内容边界」）；
  2. 等比缩放到目标边长——宽的按宽贴边，高的按高贴边，绝不拉伸变形；
  3. 居中放进 N×N 正方形——缺的那一边补全透明，输出严格 N×N。
目标适用说明
32 / 48老系统、小屏能省体积，但细节基本没了——只适合极简图标
64兼容档所有 Windows 都认，但高分屏上会偏小偏糊
96折中常见系统指针的尺寸
128推荐清晰度和体积的平衡点。导出时还能同时打包多档尺寸，系统按 DPI 自动挑
256最大4K/高分屏最锐，但文件明显变大，部分系统只取前几档
裁空白等比缩放居中补透明严格 N×N

勾上 「生成后直接设为画布尺寸并用作指针画面」就是完整的一键路径：标准图 → 画布自动改成 N×N → 放进当前角色（角色栏上写着的那个）→ 顺手猜一个热点。 不勾则只生成标准图留在 ①，你可以先精修边缘再自己点「✅ 用作指针画面」。

为什么一定要正方形？Windows 的指针画布就是正方形位图，没有"宽指针"这回事。 你给一张 16:9 的图，系统只能等比缩进去 → 左右留白、主体变小；不缩就直接变形。 标准尺寸按钮做的就是这件事，只是替你算好了。
一个元素一张图。把箭头和人物塞进同一张 128 里，两个各分一半，等于每个都只有 64。 先用 4.7 的 🧩 拆成独立元素分开，再分别生成标准尺寸，给不同角色用——这才是"清晰"的正解。

4.11三个出口：直接拿去用

抠好之后不用切块、不用导出、不用再打开别的软件。顶部操作条右边有三个出口：

按钮做什么什么时候用
✅ 用作指针画面把当前结果（自动裁掉透明边）等比缩放放进指针画布、清空旧图层、自动猜一个热点，然后跳到 ②做静态指针（90% 的情况）
🎞 加入为帧把当前结果缩放成画布大小，作为一帧追加到动画里，跳到 ②做动画：换一张图 → 再点一次 → 重复
⬇ 导出当前图 PNG导出透明背景的 PNG（文件名用顶栏的作品名）想在别的软件里再用一次
「用作指针画面」会替换当前画布底图并清空图层（图层内容可用 Ctrl+Z 撤回）。 如果你在 ② 里已经画了很多东西，先去 ② 把当前画面「🎞 加入为帧」存成帧，再回 ① 换图。

它把你放进了多大的画布？

默认 64×64。如果你的图原本很大（比如 512×512 的立绘），缩小到 64 会丢细节，建议先在 ② 右侧「画布 → 尺寸」改成 128 或 256，再回 ① 点一次「用作指针画面」。

4.12精灵图切块（可选，做动画时很有用）

只有一种情况需要它：一张图里排了很多小图（精灵图、表情包九宫格、序列帧）。单张图抠完直接用作画面即可。

框选切块

勾上「框选松手即切」后，用左侧 ⬚（快捷键 S）拖一个框，松手就直接切好一块进「素材列表」。 不勾则需要拖框后按 Enter。 「行 × 列」> 1 时会在框内等分——比如框选一整排 4 个表情、设 1 行 4 列，一次得到 4 块。

整图网格分割

按格线切整张图。填「行 × 列」+ 四边距 + 格间距 + 内缩，点「▦ 整图网格分割」。 如果精灵图带金色/浅色格线，点 🔍 可以让工具自动识别格线位置并填好边距。

切出来的块出现在底部「素材」抽屉和右侧「素材列表」。点缩略图可以进入那一块继续抠图（左上角出现「↩ 回到整图」）， 右键或双击 = 直接设为指针画面。做完可以「🎞 全部块→帧」一次性变成动画。

4.13撤销与重做

  • Ctrl+Z 撤销、Ctrl+Y 重做，也可以用顶栏的「↩ / ↪」按钮。
  • 抠图模块保留 16 步 历史，设计模块保留 40 步。超出后最早的会被丢弃。
  • 会记入历史的有：魔棒、画笔、浅色底、精修、裁切、变清晰、切块、删除素材。
  • 「重置蒙版 ♻️」= 回到图片自身的透明状态（不是变成全不透明），带透明通道的 PNG 不会被洗白。
