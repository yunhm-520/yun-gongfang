05 · ② 指针设计

这一模块决定指针最终长什么样、多大、点哪儿生效、要不要动。所有导出都以这里的内容为准。

5.1画布尺寸：先想清楚给谁看

指针画布是正方形。右侧「画布 → 尺寸」可选 16 / 24 / 32 / 48 / 64 / 96 / 128 / 256，默认 64。

尺寸适合说明
16 / 24 / 32怀旧、极简细节会丢光，只适合剪影类图形（箭头、圆点）
48 / 64日常首选64 是工具的默认值，多数显示器上清晰且文件小
96 / 128高分屏、精细图案带发丝、花纹、小字时用这个
256极限Windows 允许的最大值，文件最大，低分辨率屏上会被缩小
改尺寸会清空底图和全部动画帧（有确认弹窗）。所以顺序建议是：先在 ① 抠好图 → 到 ② 第一件事就是改尺寸 → 再点回 ①「用作指针画面」。 反过来（先做内容再改尺寸）会白做。

画布下面还有一个 像素风（最近邻缩放） 开关，只影响"缩放时怎么算像素"：

素材类型开关效果
像素画 / 游戏素材
Minecraft、FC、复古		勾上 缩放时直接取最近的像素，边缘保持硬朗，不会被平均成一团灰
照片 / 插画 / 截图不勾 缩小按面积平均、放大做插值，边缘过渡自然，不会出锯齿
放进去才发现糊？多半是画布太小。原图的短边 ≥ 96 时工具会主动问你要不要把画布升到 96/128； 已经放进去的图，改尺寸后要回 ① 重新点一次「用作指针画面」才生效（画布大小变了，旧内容不会自动重采样）。 另外：一张图里有两个元素（比如箭头 + 人物），别整张塞进 64px，用 ✂️ 裁切分开，各自做一个角色。

5.2图层：叠加与微调

指针画布由「底图 + 若干图层」合成。底图就是「用作指针画面」放进去的那张；图层用来加装饰、加字、加小标志。

操作怎么用
插入图片操作条「🖼 插入图片」或右面板「＋ 插入图片」。新图层自动缩放到不超过画布，居中放置
选中图层左侧 V（移动工具）→ 点画布上的图形，或点右面板图层列表
移动选中后直接拖。图层框是蓝色虚线
缩放图层Alt + 滚轮（以中心缩放），或用右侧「缩放」滑杆 5%~400%
旋转右侧「旋转」滑杆 −180° ~ 180°
透明度右侧「不透明」5% ~ 100%
翻转 / 居中右侧 ⇋ ⇅ / 居中，作用于当前选中图层
层级「上移 / 下移」调整叠放顺序；列表顺序 = 绘制顺序（越靠下越在上层）
并入底图把当前图层"拍平"进底图，之后不能再单独调，但可以减少运行时合成量
删除右侧「删除」或按 Delete

5.3绘图工具：补画细节

工具键说明
✥ 移动V选/拖图层（默认工具）
✏️ 画笔B自由画线，笔粗 1~24px。颜色取操作条的颜色选择器或色板
🧽 橡皮E擦掉底图上的像素（不是删图层）
╱ 直线L拖一条直线，松手落墨
▭ 矩形R拖矩形框。勾「填充形状」变成实心
◯ 椭圆O同上，椭圆/圆
🅰 文字T点画布输入，字号 6~72。「填充形状」对它无效
💧 取色I从画布取一个颜色作为当前色
📍 热点H点画布设置"点下去"的位置（下一节详述）

绘图都画在底图上，不是新建图层。画错了用 Ctrl+Z（设计模块 40 步历史）。 「🧹 清空画布」会清掉底图内容但保留图层，用来重来。

5.4热点：最容易做错的一步

热点 = 鼠标真正"点下去"的那个点。它决定了手感。做错的话指针图形是对的，但每次点击都偏半个图形，用起来极难受。

怎么设

  1. 选 📍 热点工具（快捷键 H），或直接点右面板「📍 画布点选」。
  2. 在画布上点一下正确的点。红色十字会立刻移过去，右面板「热点 X / Y」同步更新。
  3. 微调用右面板的 X / Y 数字框（范围 0 ~ 画布尺寸−1），或点「居中」「左上 0,0」快速归位。

该放在哪

  • 箭头类：箭尖（通常是图形左上方的那个尖）。
  • 手型 / 十字 / 文本 I 形：正中心。
  • 对称图形（圆、星、徽章）：正中心，或图形尖端（做装饰时）。
  • 带"指示方向"的图形：指示的那个尖端。
工具会自动猜一次：取"最上面一行不透明像素的平均 X"。箭头类基本准，其他形状请自己改。 右下预览窗里的红色小圈就是热点的实际位置，配合不同背景色看最直观。

5.5动画帧：让它动起来

多帧 = .ani 动画指针；只有 1 帧 = .cur 静态指针。

怎么加帧

  1. 做好一帧在画布上调到满意的状态。
  2. 保存成帧按 Enter，或点操作条「🎞 加入为帧」。底部托盘自动切到「帧」抽屉。
  3. 改一改再做下一帧移动图层、转一下、改个字……再按 Enter。
  4. 重复到满意为止。托盘里每一格就是一帧。

托盘里的操作

按钮作用
复制复制选中帧到它后面。做"只差一点点"的帧时最省事：复制 → 微调 → 覆盖本帧
删除删掉选中帧
← / →把选中帧往前/往后挪一位
反转整条动画倒序（做"来回摆动"时有用）
覆盖本帧用当前画布内容替换选中帧
载回画布把选中帧读回画布继续编辑（会清空当前图层）
本帧 __ ms选中帧的停留时间，10 ~ 2000ms，默认 90
时长→全部把当前这个 ms 值应用到所有帧

右下预览窗可以播放 / 暂停，缩放 1~4 倍，背景可选浅底 / 深底 / 棋盘——棋盘背景最适合检查透明边缘。

帧数别太多。3~8 帧足够；每多一帧，文件就大一圈，Windows 加载也慢。 做"呼吸感"用 2 帧 200ms 来回切就很自然。

5.6自动动画：不用手画，一键生成匹配动作

手画 8 帧太累，而且很容易"抖"。右面板「自动动画」卡片按动作预设直接算出来一组循环帧， 每帧都是一张完整的画布快照，生成后照样能逐帧改、能覆盖、能调时长。

动作默认效果与适合的角色
呼吸浮动8 帧 / 90ms上下浮动 2% 画布高度，最通用。箭头、十字、I 形都稳
呼吸缩放8 帧 / 90ms绕中心 96%~100% 轻微缩放，比浮动更"活"
旋转12 帧 / 90ms整圈匀速转，忙碌（Wait）的经典做法
弹跳8 帧 / 90ms上下弹跳 + 落地压扁，后台运行（AppStarting）很合适
摇摆8 帧 / 90ms绕底部 ±5° 摇晃，人物/手型类素材最自然
光晕脉冲8 帧 / 90ms取素材自己的主色做外发光，强度呼吸。适合"帮助"、强调态
明暗呼吸8 帧 / 90ms整图不透明度 60%~100% 呼吸，做小沙漏/后台标记很讨巧

切到某个角色时，动作下拉会自动选到推荐预设，卡片底下那行提示也会写清理由（比如「当前角色『忙碌』建议：旋转」）。

参数范围 / 默认怎么调
帧数4 ~ 16，默认 8旋转建议 12 帧才顺；呼吸类 6~8 帧够了。帧越多文件越大
每帧时长50 ~ 150ms，默认 90数字越小转得越快。整圈 12 帧 × 90ms ≈ 1.08 秒一圈
幅度30 ~ 200，默认 100动作大小。指针本身很小，幅度大了会显得"抽"，100 通常就够
生成后还能改。自动动画只是"填好一堆帧"，帧托盘照常可用：选中某帧 → 改画布 → 「覆盖本帧」， 或「复制」后微调。想加一点手绘细节（比如眨个眼），就在生成结果上改两帧。
只有多帧才导出 .ani。生成后至少保留 2 帧，否则这个角色会导出成静态 .cur（动画自然消失）。 另外：热点位置不随动画移动，浮动/摇摆类动作的"位移"只是视觉，点击点始终在同一个像素上。
动画帧的封装格式参考了 damieng/Anim8Cursor 的 .ani 帧结构（每帧含独立热点 + rate 块）， 预设动作本身是工具里用 Canvas 变换实时算的，不依赖外部服务。

5.717 个指针角色：每个角色一份独立作品

Windows 的指针不是一张图，是 17 个"角色"（正常箭头、忙碌、文本 I 形、手型……）。 以前的工具是一份作品通吃 17 个角色，做着做着就糊涂了：我这一笔是画给谁的？

现在改成每个角色一份独立作品：切换角色时自动保存当前这份的画布、图层、全部动画帧、热点， 再载入目标角色的那一份。互不干扰，切回来一模一样。

三处地方都会告诉你"现在是谁"

位置显示内容
画布上方角色栏「正在编辑 正常选择 · Arrow → pointer.cur」+ 状态标签（空白 / 静态 / 12 帧动画）；右边 17 个胶囊，当前那个是深蓝高亮，有内容的角色带绿点
顶栏标签页「② 指针设计 · 忙碌」——切到哪个角色，标签上就写哪个
右面板第一张卡片大号角色名 + 导出文件名 + 状态；下面 17 个角色按钮，绿点表示这个角色已经有作品
  • 点角色栏里的「忙碌」——画布清空（因为忙碌还没做过），角色栏立刻变成「正在编辑 忙碌 · Wait → busy.cur」
  • 做这一份：从 ① 用作指针画面、或直接画、或用下面的「自动动画」生成帧
  • 点回「正常选择」——刚才的箭头原封不动回来了，忙碌那份额外存着
    • 没做的角色怎么办？导出时沿用当前正在编辑的那一份，和旧版行为一致——只做一个箭头也能导出完整皮肤。 想给某个角色用别的图，就在导出面板那一行点 「去编辑」，会直接关掉面板、切到那个角色的画布上。
    换角色 = 换工作区。撤销历史（Ctrl+Z）是按角色分开的，切过去之后撤不回上一个角色的操作； 文件也不会自动存盘——关页面前记得导出。

    5.8实景试戴：导出前先看一眼

    做完指针最怕的是"装上才发现不对"。顶栏的 👁 试戴 会在一个模拟桌面上 把你的指针按真实像素尺寸放进去，还自带文档、按钮、窗口边框——鼠标移过去， 它就会像在真系统里一样切换角色。

    1. 点顶栏 👁 试戴。没有作品时会提示先回 ① 抠图；有作品就直接进桌面。
    2. 把鼠标移到预览区里。移到正文 → 变 I 形（文本选择）；移到按钮/链接 → 变手型； 移到窗口边缘 → 变调整大小双箭头；移到桌面空白 → 变回箭头。这就是装好后的真实反应。
    3. 看红色十字。它标的是热点——也就是系统认为你"点下去"的那个像素。 如果十字落在图案左上角、而你想让它落在笔尖或箭头尖上，回 ② 用 H 键重设热点。
    4. 多帧作品会自动循环播放，帧率就是你在底部调的每帧毫秒数，不用手动点播放。

    上排四个开关分别管什么

    控件作用
    尺寸32 / 48 / 64 / 96 / 128 px。选 32 看小尺寸糊不糊，选 96 看大尺寸细节够不够。
    放大1× 是真实大小；2× / 3× 只是放大观察，窗口里会标注"放大显示"，不代表实际会变大。
    场景桌面（深色壁纸 + 图标）、文档（白底）、深色（暗色界面）、棋盘（透明区可见）。 浅色图案在深色场景里最容易被看出白边，深色图案在文档场景里最容易看出毛边。
    热点关掉红色十字，只留一个小圆点，适合看整体效果时用。
    示范鼠标不进去时，指针会自己沿路径走一圈（正文 → 按钮 → 右下角 → 右边缘）， 用来快速看完整套角色切换。

    下面一排是角色胶囊：默认选中 🎯 自动，按位置自动切换； 点任意一个角色（比如"忙碌"）就锁定成那个角色，方便单独看它在深色和浅色背景上的效果。 锁定后鼠标怎么移都不变，点回「自动」才恢复。

    两个常见误区。一是别在 1× 下判断清晰度——32px 的指针本来就只有指甲盖大小， 看着糊是正常的，真正要判断的是"在 2× 下边缘有没有白边、热点有没有偏"。 二是试戴不能替代导出后实装：Windows 在不同缩放比例（100% / 125% / 150%）下会自己挑不同尺寸， 试戴看到的是"像素本身"，实装还要看系统怎么缩放。

    06 · ③ 导出与安装

    6.1导出对话框

    点右上「📦 导出皮肤」打开。需要填/确认的只有四项：

    字段默认说明
    皮肤名称= 顶栏作品名会出现在「鼠标属性 → 指针 → 方案」下拉里，也用作文件夹名。建议用中文短名，别带 \ / : * ? " < > |
    指针尺寸= 当前画布.ani 动画帧的尺寸（32/48/64/96/128/256）。静态 .cur 不用这个，用下面的多尺寸
    .cur 多尺寸48 / 64 / 96一个 .cur 文件里打包多个尺寸，Windows 按当前 DPI 自动挑。全不勾时回落到 48/64/96；画布比勾选的大时会自动补一档，不白丢清晰度
    角色表17 行分别是「单独制作 / 沿用当前作品 / ✔ 外部文件」三列按钮：去编辑（关面板直接切到那个角色的画布）、换文件（用你自己的 .cur/.ani 顶替）、恢复（清掉外部文件）

    对话框底部四个按钮：导出 CUR（只导一个静态指针文件）、导出 ANI（只导一个动画文件）、 导出 INF（只导一个 Install.inf）、导出 ZIP（推荐）——一次给齐所有文件 + 脚本 + 说明。

    17 个角色是怎么出的？按顺序判断：① 你给这一行指定了外部文件 → 用外部文件； ② 这个角色在 ② 里单独做过（角色栏有绿点）→ 用它自己那份，多帧就出 .ani、单帧出 .cur； ③ 都没做 → 沿用你当前正在编辑的那一份。所以"只做一个箭头"也能导出完整皮肤，不会缺角色。

    6.2ZIP 里到底有什么

    文件作用
    17 个 .cur / .ani每个指针角色一个文件，文件名固定（pointer / work / busy / hand …）
    Install.inf方案定义。声明"把这些文件复制到 Cursors\皮肤名\，并在 Schemes 下注册一个叫皮肤名的方案"
    安装皮肤.bat申请管理员 → 复制文件 → 注册方案。装完才有得选
    立即启用.bat不用打开控制面板，直接写注册表并通知系统刷新（想立刻看到效果就用它）
    卸载皮肤.bat只删自己那一项方案和文件夹
    恢复默认指针.bat把当前指针切回 Windows 默认方案
    立即生效.ps1 / 恢复默认.ps1上面两个 bat 调用的 PowerShell 脚本（调用系统 API 立即刷新，不重启资源管理器）
    说明.txt角色 ↔ 文件名对照表，方便以后手动改

    6.3安装（三步）

    1. 解压 ZIP到任意位置（桌面、下载都行）。不要只把 bat 拖出来单独运行，它需要旁边的指针文件和 INF。
    2. 双击「安装皮肤.bat」。会弹 UAC 问是否允许管理员权限，点「是」。 看到「完成」后按任意键关闭窗口。
    3. 应用打开「控制面板 → 鼠标（或 设置 → 蓝牙和其他设备 → 鼠标 → 其他鼠标设置）→ 指针」， 在「方案」下拉里选你的皮肤名 → 点 应用 → 确定。
    懒得进控制面板：直接双击「立即启用.bat」，它会把注册表写好并让系统立刻刷新，鼠标当场变。之后方案下拉里同样能看到你这一项。

    装完想改 / 想撤

    想要做法
    切回系统默认外观双击「恢复默认指针.bat」，或方案里选「Windows 默认」
    彻底删掉这套皮肤双击「卸载皮肤.bat」（删方案项 + 删文件夹）。建议先切回默认再卸载
    改了一版重新装再跑一次「安装皮肤.bat」会覆盖同名文件夹，然后「立即启用.bat」
    只换某一个角色把新文件按「说明.txt」里的名字（如 work.ani）覆盖进 C:\Windows\Cursors\皮肤名\，再点「立即启用.bat」

    6.4为什么它不会弄坏系统

    • 导出的指针文件放在 C:\Windows\Cursors\你的皮肤名\ 这个独立文件夹里，不覆盖任何系统文件。
    • 注册表只往 HKCU\Control Panel\Cursors\Schemes 下新增一个键值，不动 Aero 系列的 17 个默认项。
    • 所以「鼠标属性」里看到的仍然是：Windows 默认、Windows 黑、Windows 反转……+ 你的皮肤名。随时可以切走、切回。
    • 安装脚本里做了一件小事：先把文件复制到临时目录再调系统安装接口。原因是 INF 安装路径含中文时容易失败，这样绕开了。
